# StraboSpot

**StraboSpot** ([strabospot.org](https://strabospot.org/)) is a geologic data system that allows researchers to digitally collect, store, and share both field and laboratory data. It is built around the concept of a *spot*: any observation that characterizes a specific area, at any spatial scale, from regional maps to microscopic images.

The StraboSpot ecosystem includes:

- **StraboField**: iOS/Android and web application for collecting geologic field data ([repo](https://github.com/StraboSpot/StraboField))
- **StraboMicro**: application for managing microstructural and microscopy data ([repo](https://github.com/jasonash/StraboMicro2))
- **StraboExperimental**: web application for experimental rock deformation data ([repo](https://github.com/StraboSpot/StraboExperimental))
